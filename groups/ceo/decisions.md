# CEO Decision Log

*Append-only log tracking Jeff's choices and the patterns they reveal.*

## Purpose

This file captures moments when Jeff overrides, redirects, or makes an explicit choice that diverges from what the CEO agent proposed or would have done by default. Over time, these entries build a picture of Jeff's preferences, priorities, and decision-making patterns — so the CEO can anticipate what he'd want rather than guess.

*This log is append-only.* Never edit or delete past entries. New insights go at the bottom.

## Format

Each entry must include these four fields, in order:

- *Date* — ISO date (YYYY-MM-DD) when the decision happened
- *Context* — what was being decided, what the CEO proposed or was about to do
- *Jeff's choice* — what Jeff actually said/chose/redirected to
- *Pattern revealed* — the underlying preference or principle this entry points to

### Template

```
### YYYY-MM-DD — <short title>

*Context:* <what was on the table, what CEO proposed>
*Jeff's choice:* <what Jeff decided or redirected to>
*Pattern revealed:* <the underlying preference or principle>
```
